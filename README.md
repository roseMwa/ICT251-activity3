## Project Overview
This repository contains Activity 3 for ICT251 Web Technologies. It is a responsive student portfolio showcasing semantic HTML5, custom CSS styling, and dynamic JavaScript user interactions.

## JavaScript Features Implemented
1. **Compulsory Contact Form Validation & Preview**: Validates name, email, and message inputs using `event.preventDefault()` to stop page reloads, presenting a client-side preview summary.
2. **Theme Switcher**: Toggles between light and dark visual modes.
3. **Expandable Content**: Shows or hides detailed technical summaries for portfolio projects.
4. **Study Hours Calculator**: Calculates weekly target study hours and validates numeric/boundary inputs (1–7 days).
